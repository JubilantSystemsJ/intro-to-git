# Gitea Guide

## When Gitea is useful

Gitea is a lightweight self-hosted Git platform that works well for classrooms with unreliable internet, internal lab networks, or small teaching environments where you want more control.

## How students use it

Students use Gitea much like GitHub or GitLab:

- clone a repository
- create a branch
- commit and push changes
- open a pull request if that feature is enabled
- review and merge changes

## Why use it in class

- smaller and easier to self-host
- useful on local classroom networks
- familiar enough for Git workflow teaching

## Limitations compared with larger platforms

- fewer advanced enterprise features
- smaller ecosystem
- interface and workflow features may be simpler than GitHub or GitLab

## Teaching note

Use Gitea when reliability and local control matter more than platform polish. The Git concepts stay the same.
